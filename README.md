<h1 align="center">先别付钱 · Hold My Wallet</h1>

<p align="center"><strong>不替你做消费决定，先帮你算清已知成本、看见关键未知项，再决定下一步。</strong></p>
<p align="center">一个面向购物、续费、分期和签合同场景的 AI 决策技能。可用于支持 Agent Skills 的 AI 助手，也可以把文件作为普通上下文交给其他助手。</p>
<p align="center"><img alt="Validate Skill: passing" src="https://img.shields.io/badge/Validate%20Skill-passing-brightgreen"> <img alt="License: MIT" src="https://img.shields.io/badge/License-MIT-yellow"></p>

如果它帮你少一次冲动消费，或在付款前发现一项重要未知，欢迎点亮 ⭐ Star，也欢迎 Follow 关注后续更新。仓库暂不展示星数。

很多消费页面会把注意力放在“限时优惠”“每月只要……”或一行大字上。先别付钱会把促销页、账单和合同拆成看得到的原文、你提供的信息、基于材料的推断和仍然未知的部分；金额用随附 Python 工具按明确输入计算。这样你能比较实际承诺的总成本，而不是让模型猜价格、历史成交或隐藏条件。

它不替你做“买/不买”的价值判断。它会说明哪一条信息可能改变结论、现在能做的可逆核实步骤是什么；没有页面、条款或凭证支持的内容，直接标为未知。

## 它能帮你解决什么

| 你遇到的问题 | 先别付钱会怎么帮 |
| --- | --- |
| 不清楚所谓“原价”“限时折扣”怎么算 | 抽取商品规格、展示价、比较价、券和附加条件，标出页面差异与缺失证据 |
| 试用期快结束，不知道会扣多少钱 | 列出扣款渠道、试用截止、续费金额/周期与取消确认；缺项留为未知 |
| 分期只展示低月供 | 按首付、每期金额、期数和明确费用汇总已知支出，不把未写费用当作零 |
| 租房、培训、维修或服务合同太长 | 提取付款、押金、续约、取消、退款、违约和责任条款原文与位置 |
| 不确定现在是否该付钱或签字 | 解释结论依赖哪些事实，给出一个可撤回的核实动作，由你决定是否继续 |

## 安装

### 支持 Agent Skills 的 AI 助手

如果你的助手能够从 GitHub 或本地目录安装 Agent Skills，把下面这段发给它：

```text
请从 https://github.com/yifanchen12/hold-my-wallet 安装先别付钱（Hold My Wallet）Agent Skill。保留 SKILL.md、references 和 scripts；安装前说明目标 Skill 目录，不要替我付款、续费、下单或签合同。
```

不同助手的 Skill 目录、加载方式和调用语法可能不同。完成安装后，按产品自身说明重新加载技能；有些助手支持 `$hold-my-wallet`，也可以直接说“使用先别付钱帮我……”。

### 没有 Agent Skills 安装功能的 AI 助手

把 `SKILL.md` 和与问题最相关的一份指南一起提供给助手，并说明“请按这份流程分析”。如果需要精确汇总金额，还要在本地运行仓库里的 Python 脚本；无法运行脚本的助手只能整理数字，不能声称已经完成了精确计算。

## 第一次使用

可以直接讲情况，不用补齐所有字段。材料越少，结论中的未知项就越多。

```text
场景：网购促销 / 自动续费 / 分期付款 / 租房或服务合同
我正在考虑：购买 / 续费 / 签约 / 暂缓
页面或合同原文：粘贴相关片段，或附遮挡隐私后的截图
明确金额和日期：仅填写页面/凭证写出的数字
我最关心：总支出 / 续约 / 取消 / 退款 / 其他
请输出：原文证据、计算、推断、未知项和现在可做的一步
```

不必提供账户密码、验证码、完整银行卡号、身份证号码或无关个人信息。若合同或账单很长，只给需要分析的条款，并遮住姓名、地址、账号等字段。

## 一个典型回答如何产生

```text
用户材料
  → 识别是促销、续费、分期还是合同问题
  → 摘录可定位的原文证据并区分用户口述
  → 只加载当前场景需要的指南和来源
  → 金额交给 Python Decimal 脚本按明确输入汇总
  → 列出推断与未知项，避免把不完整小计说成总价
  → 给一个可逆的核实动作和待确认问题
```

例如，页面写明首付 200 元、每月 100 元共 10 期、手续费 30 元，已知小计是 **1,230 元**。提前结清费用没有写出，就应标记为未知，而不是 0 元；下一步可先查完整协议中的提前结清与逾期条款。

脚本输入输出见 [`examples/`](examples/)。本地计算方式：

```bash
python scripts/cost_calculator.py < examples/input.json
```

PowerShell：

```powershell
Get-Content -Raw examples/input.json | python scripts/cost_calculator.py
```

## 局限与隐私

- 不联网查价、不登录商家账户、不读取历史订单，也不验证历史最低价、库存或商家动机。
- 不会自动付款、下单、取消续费、接受条款或签署合同。
- 法律规则按地区、交易类型和事实适用；合同提取不是法律意见，也不认定个案违法。重大金额或争议请向当地官方/专业渠道核实。
- 金额脚本只计算明确输入，不推测税费、汇率、未来涨价、退款或隐藏费用；任何未知成本都不会被当作零。
- 脚本在本地运行，不联网、不保存输入。不要把真实账单、合同或个人资料提交到公开仓库。
