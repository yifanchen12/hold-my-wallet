# 先别付钱 · Hold My Wallet

> **下单、续费、分期或签合同之前，先把已知成本算清，把关键未知项找出来。**
>
> 面向支持 Agent Skills 的 AI 助手，也可以把文件作为普通上下文交给其他 AI 助手使用。

先别付钱会把页面、账单或合同里的原文证据，与用户提供的信息、推断和未知项分开。金额由随附 Python 工具按明确输入计算；Skill 不会凭空补出历史价格、隐藏费用、商家动机或法律结论。

## 它能帮你处理什么

| 你遇到的情况 | 先别付钱会怎么帮 |
| --- | --- |
| 促销倒计时、优惠券和“原价”看不明白 | 摘出标价与优惠条件，指出还缺哪些结算信息 |
| 免费试用后自动续费 | 列出试用期、续费金额、周期和扣款日期；未知项保持未知 |
| 分期页面只突出“每月很低” | 用明确的首付、期数和费用汇总总支出，并标出未计费用 |
| 租房、培训、维修或其他服务合同太长 | 提取押金、续约、取消、退款、责任等条款原文与位置 |
| 想知道现在要不要买/签 | 比较已知条件，给出一个可逆的核实步骤；决定权留给你 |

## 安装与使用

### 支持 Agent Skills 的助手

如果你的助手能从 GitHub 或本地目录安装 Agent Skills，可以把公开仓库地址发给它，要求它安装 `hold-my-wallet`：

```text
请将 https://github.com/yifanchen12/hold-my-wallet 安装为一个本地 Agent Skill。保留仓库中的 SKILL.md、references、scripts，不要执行任何交易操作。
```

技能目录和安装方式由各助手决定。安装后重新加载/开启该助手的 Skill 功能；有些产品支持 `$hold-my-wallet`，有些使用名称或自然语言调用，具体以产品说明为准。

### 其他 AI 助手或手动使用

若助手没有 Skill 安装功能，把本仓库的 `SKILL.md` 和当前问题对应的一份 `references/` 指南一起附上，并告诉它“请按这份流程分析”。涉及金额时，还需在可本地运行 Python 的环境运行 `scripts/cost_calculator.py`；否则不要让模型心算并声称精确结果。

## 第一次使用，可以这样提供材料

不必填完整表格，已有多少信息就给多少。未知项可以留空。

```text
场景：商品促销 / 自动续费 / 分期 / 租房或服务合同
我正在考虑什么：购买 / 续费 / 签约 / 暂缓
页面或合同原文：粘贴相关片段，或提供遮挡个人信息后的截图
已知金额与日期：只填页面明确写出的数字
我最在意的事：总支出 / 取消条件 / 退款 / 其他
希望得到：证据、计算、未知项，以及现在可做的一步
```

不要为了使用 Skill 提供账户密码、验证码、银行卡完整号码或身份证完整号码。

## 一个典型回答会长这样

```text
### 目前能确认
- 页面写明：首付 200 元，每月 100 元，共 10 期；手续费 30 元。
- 你提供：考虑购买，尚未付款。

### 已知费用
- 200 + 100 × 10 + 30 = 1,230 元（不含未提供费用）。
- 提前结清费用：未知；不能按 0 元计算。

### 建议先做
- 付款前查看完整协议中的提前结清、逾期和退款条款。
```

更多输入输出见 [`examples/`](examples/)；金额脚本也可单独使用：

```bash
python scripts/cost_calculator.py < examples/input.json
```

PowerShell：

```powershell
Get-Content -Raw examples/input.json | python scripts/cost_calculator.py
```

脚本只对明确输入做算术汇总，不验证网页价格或条款真伪。

## 参考资料与知识库

`references/` 中的场景指南帮助整理问题；[`references/knowledge/`](references/knowledge/README.md) 是带来源和适用边界的资料库，涵盖价格证据、订阅、分期和合同条款。只读取与当前问题相关的资料。平台规则和法律可能更新，知识条目不是个案法律、财务意见。

## 局限与隐私

- 不自动登录、查价、付款、取消订阅、下单或签署合同，也不核实商家历史成交价。
- 不把促销文案直接定性为欺诈；法律适用、合同效力和争议结果需要按所在地与事实向官方/专业渠道核实。
- 计算器只算用户提供的金额与次数；税费、汇率、未披露费用、退款和未来价格变动不作猜测。
- 脚本本地运行、不联网、不保存输入。不要把真实账单、合同或个人信息提交到公开仓库或公开聊天。
