# 合同文字与消费者权益

## 提取，不替用户裁决

逐项摘录合同中与现金流和退出成本有关的原文，并标出页码/段落：总价和付款节点、押金/定金、续约、解除/取消、退款/扣款、违约责任、服务范围、争议处理、单方变更。区分“条款原文”“通俗释义”“需要核实的问题”。看不到的附件、引用规则和口头承诺一律注明缺失。

## 中国消费者交易的官方参照

中国《消费者权益保护法》包含网络购物七日无理由退货的一般规则及其例外，也对经营者提供的格式条款作出消费者权益保护要求。适用与否要结合商品/服务类型、交易事实、法定例外、约定与现行规则判断，不能从单个条款片段直接推出“合同无效”或“必然可以退款”。官方文本：[国家市场监督管理总局转载：《中华人民共和国消费者权益保护法》](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_615af9ed6bcd4974bf853dd2e02bc663.html)。

## 向用户呈现

```text
原文（第 X 页/第 X 条）：……
字面意思：……（只解释文本表述）
对你可能重要：……（标成推断）
还缺少：附件 / 补充协议 / 付款凭证 / 适用地区 / 生效日期
建议核实：向合同相对方书面询问……；重大争议咨询当地法律专业人士
```

签字/支付前的可逆步骤包括索取完整合同与附件、确认金额和日期、把口头承诺写入书面补充约定、暂缓签署直到疑问有答复。不要代用户接受条款或作法律定性。

## 范围与时效

以上法律来源是中国官方文本，不自动适用于境外、商事合同或所有服务关系。引用时核对当前法规、交易性质与当地规则；高金额、住房、人身安全或重大权利争议应转交有管辖权的专业人士/官方机构。
