# 先别付钱｜参考资料与知识库

这是一份精简的来源索引，不是法律/财务意见，也不是实时价格数据库。以下页面在 **2026-10-22** 整理；平台帮助页和法规可能更新，实际决策前请打开原始链接核对现行版本、适用地区和交易页面。

## 怎么读

| 资料 | 适用问题 | 来源性质 / 范围 |
| --- | --- | --- |
| [价格宣传与促销证据](价格宣传与促销证据.md) | 比价、折扣、促销条件 | 中国市场监管部门规章；只用于提示核对点，不据此认定个案违法 |
| [订阅与分期付款核对](订阅与分期付款核对.md) | 续费、试用、分期、先买后付 | Apple/Google 当前帮助页；CFPB 资料只描述美国监管范围内信息 |
| [合同文字与消费者权益](合同文字与消费者权益.md) | 租房或服务合同条款提取 | 中国消费者权益保护法官方文本；不适用于所有合同类型/地区 |

## 来源等级

- **A｜一手规范/主管机关**：现行法规、监管机关规章或官方解释。可用于定位应核对的条文，不能让 AI 替代执法、裁判或律师意见。
- **B｜平台官方帮助**：仅说明该平台公开的账户操作/产品信息；不推定其他平台、地区或账户适用。
- **C｜用户材料**：截图、订单、合同、账单原文。它们是个案分析的主要证据，但截图不一定完整或仍然有效。
- **D｜分析提示**：技能自己的核对清单与算账口径，不是外部事实来源。

金额一律以用户提供且能定位到页面/协议的数值为准；“没看到”标为未知，不推断为零。任何价格计算仍走 `scripts/cost_calculator.py`。
