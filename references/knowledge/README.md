# 先别付钱｜参考资料与知识库

这份资料库收录 100 项法规、监管指引、官方帮助和研究资料，覆盖促销证据、订阅续费、分期成本、住房租赁与服务合同。每次只按当前问题加载少量条目；页面内容、适用地区和平台流程可能变化，引用前应核对原文及生效状态。

## 资料导航

| 条目 | 用途 |
| --- | --- |
| [价格宣传与促销证据](价格宣传与促销证据.md) | 把页面展示、促销规则和结算金额拆开记录 |
| [订阅与分期付款核对](订阅与分期付款核对.md) | 续费节点、取消路径、分期总成本及不确定费用 |
| [合同文字与消费者权益](合同文字与消费者权益.md) | 提取义务、期限、费用、续约、解除和违约条款 |
| [来源索引（100 项）](来源索引.md) | 法规、官方指引、平台帮助及研究资料的分级书目 |

## 使用约定

- **A｜法律法规 / 监管原文**：说明规则文本，不自动推出个案结论；地区、主体、交易类型和生效日期都要核对。
- **B｜官方消费者指引 / 平台帮助**：说明公开流程或一般消费者信息，不能保证具体账号、订单或商家的结果。
- **C｜研究 / 方法资料**：帮助理解决策偏差、合同阅读或消费行为，不替代用户材料与现行规则。
- **用户材料｜一手交易证据**：页面、合同、订单、账单、客服记录和用户口述；保留来源与取得时间，避免把片段当成完整事实。

每次回答必须区分**原文证据、用户提供、推断、未知项**。计算金额使用随附 Python 脚本；不补造历史价格，不判定商家欺诈，不代替律师或监管部门作法律结论。不要上传含地址、证件、支付凭证等信息的材料到不必要的服务。
