# 价格宣传与促销证据

## 用途

帮助把“原价、折扣、限时、券后价、满减、赠品”等说法转成待核对的信息项。此页不判断商家是否违法，也不验证历史价格。

## 先记录页面上的可见信息

- 商品/服务具体规格、数量与计价单位。
- 当前展示价、划线价或比较价分别标注的含义。
- 促销规则全文：适用商品、资格/会员条件、券的门槛、数量限制、有效期、运费及附加服务费用。
- 结算页最终应付金额、优惠明细和时间；保存页面截图或订单摘要，保留来源与采集时间。
- 商品页面、详情页、购物车和结算页的金额/条件是否一致。不同页面冲突时，先视为证据不完整。

## 官方规则所提供的核对方向

中国市场监管总局《明码标价和禁止价格欺诈规定》要求网络销售通过页面明码标价，并规定比较价格、折价/减价基准和网络促销信息等方面的要求。AI 可以指出“比较价的定义或促销条件页面没有写清”等可观察问题，但不得只凭一张截图认定经营者违反规定。规则页面：[国家市场监督管理总局：明码标价和禁止价格欺诈规定](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_9a1f82a007964950a1a0f6c056f2fedf.html)。

## 输出约定

| 项目 | 记录方式 |
| --- | --- |
| 原文证据 | 短摘录 + 页面/截图位置 + 日期；不要扩写为法律结论 |
| 用户提供 | 用户口述的结账体验或商家沟通，注明未独立核实 |
| 推断 | 只说明页面间的差异、规则缺口或数字关系，并解释依据 |
| 未知项 | 历史成交价、库存、资格、结算后费用、商家主观意图等 |

如用户怀疑价格问题，先建议保存促销页、详情页、结算页、支付凭证和沟通记录，再自行通过有管辖权的官方渠道咨询/投诉。不要替用户公开指控商家。

## 边界

引用法规时应先核对页面是否更新、经营者及交易是否在该规则适用范围内。促销“看起来不合理”不是欺诈证据；消费者保护、跨境交易和行业规则可能不同。这里只提供证据整理，不提供个案法律意见。
